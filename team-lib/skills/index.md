# skills

## Purpose
Shared capability modules for team use.

## What Belongs Here
- Team-standard skill definitions
- Shared tool configurations
- Common capability modules

## What Does NOT Belong Here
- Personal skills (use `my-lib/`)
- Execution workflows

## File Naming Conventions
- Every skill is a directory, `<skill-name>/`, holding a `SKILL.md` whose frontmatter carries `listing` and `category` (see the AGENTS.md metadata standard).

## How Agents Should Use This Folder
Find skills with the `find-skill` skill (keyword and `--categories` over the generated registries) rather than browsing this folder; load the one it returns. Third-party skills under `_external/` are listed `user-only` by default, with exceptions in `config/skill-listing.yaml`.

| Directory | Contents |
|-----------|----------|

| `_external/` | Third-party skills — do not modify |
