# skills

## Purpose
Shared capability modules for team use.

## What Belongs Here
- Team-standard skill definitions
- Shared tool configurations
- Common capability modules

## What Does NOT Belong Here
- Personal skills (use `my-lib/`)
- Execution workflows

## File Naming Conventions
- `<skill-name>.md` or `<skill-name>/` for complex skills

## How Agents Should Use This Folder
Load shared skills for team task execution.
