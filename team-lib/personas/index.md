# personas

## Purpose
Define team-approved agent identities and configurations.

## What Belongs Here
- Team persona definitions
- Role-specific configurations
- Project-specific agent identities

## What Does NOT Belong Here
- Personal personas (use `my-lib/`)
- Directives or skills

## File Naming Conventions
- `<persona-name>.md` or `<persona-name>.yaml`

## How Agents Should Use This Folder
Load team personas for team task execution.

Every persona declares `skill_categories:` in its frontmatter when it is created (names from `team-lib/config/skill-categories.yaml`; derived into `registry/personas.yaml`). On load it passes them to the `find-skill` skill (`find_skill.py --brief --categories <list>`) to get its current skills, instead of keeping a hand-written table of tools that goes stale the day a skill is added.
