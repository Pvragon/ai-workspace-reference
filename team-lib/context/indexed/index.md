# indexed

## Purpose
Searchable team knowledge base for on-demand retrieval.

## What Belongs Here
- Detailed project documentation
- Team reference materials
- Historical project information

## What Does NOT Belong Here
- Always-needed context (use `global/`)
- Personal notes

## File Naming Conventions
- `<project>-<topic>.md` for categorization

## How Agents Should Use This Folder
Query using semantic search when specific team/project context is needed.
